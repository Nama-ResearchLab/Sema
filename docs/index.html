Verification Standards

Sema is tested against a comprehensive gold benchmark suite covering complex Bantu verbal morphology. In addition to unit tests, our closed-loop verification decompiles each synthesized form through the forward linearizer to prove that subject concords, tense markers, and polarity remain character-for-character identical.

Model Context Protocol (MCP) Server

Integrate Sema directly into modern agent environments including Claude Desktop, Cursor, and Antigravity.

Claude Desktop Configuration

Add Sema as an offline MCP tool provider by updating your configuration file:

claude_desktop_config.json
{
  "mcpServers": {
    "sema": {
      "command": "sema-gui",
      "args": ["--mcp"]
    }
  }
}

Available Agent Tools

  • sema_morph: Deconstruct any Swahili surface verb into structured morpheme slots.
  • sema_synth: Build an exact, verified Swahili verb from intent parameters.
  • sema_terms: Shield clinical vocabulary and quantities behind deterministic tokens.
  • sema_lexicon: Query word lemmas, grammatical roles, and translations offline.
