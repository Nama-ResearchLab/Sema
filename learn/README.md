# Learn Sema: a mini-course from zero

No background needed. Each lesson defines every new word when it first
appears, shows small examples, then lets you run the real thing. Go in
order. Roughly 10 minutes per lesson plus trying commands yourself.

![Nama Research Lab](assets/nama-logo.png)

## How to use this course

Read a lesson, then run its "Try it" commands in a terminal from the
repository root. If a command fails, check you are inside the right
repository folder first. Interactive pages need only a browser, no
server and no network.

## The course

1. [First principles](01-first-principles.md) (start here): the problem,
   the core idea, and the vocabulary the rest of the course uses.
2. [Forward: anchoring](02-forward-anchor.md): turning Swahili words
   into English meaning skeletons.
3. [Back-pass: rendering](03-backpass-render.md): turning structured
   meaning back into exact Swahili verbs.
4. [Proof, not promises](04-proof.md): every benchmark, what it means,
   and how to reproduce it.
5. [Use it](05-use-it.md): command line, library recipes, and the app.
6. [References](refs.md): where the data comes from and what to read next.

Interactive: [course hub](index.html) (guided build plus quiz),
[verb explorer](verbs.html) (pick slots, see real engine output), and
[glossary](glossary.html) (hover any term for its definition).

Print: every HTML page uses print-friendly CSS, so any lesson exports
to PDF from the browser print dialog.
