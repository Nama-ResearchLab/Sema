# References and Provenance

## Data Sources

- Wiktionary via Kaikki dataset exports: the raw source for the 19,717 headword lexicon. Used for rebuilding or extending the dictionary under Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).
- Curated starter dictionaries: starter tab-separated values (TSV) files in data/terms.clinical.tsv and data/terms.core.tsv written directly by the engine author as an initial test vocabulary (unreviewed by independent native speakers).

## Morphological Principles

- Agglutinative verbal slot templates: standard Bantu 10-slot verbal structure covering subject concords, tense-aspect-mood (TAM) markers, object infixes, root stems, derivational extensions, and final mood vowels.
- Asymmetric vowel height harmony: phonotactic harmony rules governing applicative (-ia / -ea) and stative (-ika / -eka) verbal extensions based on mid-vowel and non-mid-vowel stem distributions.
- Prosodic minimality constraints: penultimate stress assignment in Bantu languages requiring epenthetic stabilizer insertion (-ku-) for monosyllabic verbal roots in affirmative indicative tenses.
